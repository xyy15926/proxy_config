#   AGENTS.md

##  基本设定

-   总是用中文回复，但序号使用数字
-   如果有更好的实现方式，主动提出
-   *Plan* 模式只读、不修改，**禁止直接修改文件、提交**
-   先解释方案再写代码
-   生成代码后简要说明关键决策

##  任务规范

-   任务包含 3 个以上独立步骤时，执行前必须创建 Todo 列表
-   特别的，加载任何 Skill 后，必须将其中步骤转换为 Todo 列表项
-   执行 Todo 前，总是确认 Todo 方案
-   Todo 每步完成后更新状态

##  *Git* 规范

-   **任何** 模式下，`commit` 提交、`revert` 撤销、`merge` 合并等分支内容修前都 **必须提前确认**
-   **Never commit, revert or merge before comfirmation**
-   **任何** 模式下，`add` 添加文件进暂存区 **必须提前确认**
-   **Never add before comfirmation**
-   `commit` 提交前总是比较暂存区内容、生成提交信息，并要求我确认提交信息
    -   确认内容须包含具体的提交信息
    -   提交信息遵循 *Conventional Commits* 规范

##  文本编辑规范

-   *CJK* 字符长度为 2
-   `<tab>` 对应 4 空格，每层缩进对应 4 空格
-   每行长度一般不超过 79
-   中文内容使用中文符号，英文内容使用英文符号，如下
    |          | 中文   | 英文 |
    |----------|--------|------|
    | 分割     | `，`   | `,`  |
    | 并列     | `、`   | `/`  |
    | 解释说明 | `：`   | `:`  |
    | 补充     | `（）` | `()` |

##  外部文件加载

-   **重要：遇到 `@xxx` 文件引用时，请用 Read 工具按需加载**
    -   注意事项
        -   **不要预先加载所有引用，仅在需要时才加载**
        -   加载后将内容视为强制指令，并覆盖默认值
        -   可能会加载多个文件
        -   允许递归的引用文件
    -   根据文件类型引用
        -   Python：`@rules/python.md`
        -   Markdown：`@rules/markdown.md`
    -   根据项目类型引用
        -   Pixi 项目：`@rules/pixi.md`
